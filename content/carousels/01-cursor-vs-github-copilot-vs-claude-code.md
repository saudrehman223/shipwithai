## Slide 2 — Quick verdict
**The one-line answer:**
- 🚀 Want an all-in-one AI IDE? → **Cursor**
- 💰 Best value, keep your editor? → **GitHub Copilot**
- ⌨️ Live in the terminal? → **Claude Code**

## Slide 3 — Cursor ($20/mo)
**The AI-native IDE.**
- Multi-file agent edits — refactor whole flows, not one file
- Indexes your full codebase
- It's VS Code under the hood — extensions carry over
⚠️ Watch out: $20/mo, and heavy agent use burns the usage pool fast.

## Slide 4 — GitHub Copilot ($10/mo)
**The best value.**
- Cheapest serious option — $10/mo, unlimited completions
- Lives inside the editor you already use
- Free tier: 2,000 completions/month (genuinely useful)
⚠️ Watch out: agent mode is competent but third — it's a completion tool first, reasoning tool second.

## Slide 5 — Claude Code ($20/mo)
**The terminal agent.**
- Strongest reasoning of the three — plans before it writes
- Genuinely autonomous: issue → explore → fix → test → summarize
- No editor lock-in
⚠️ Watch out: no free tier at all, and weekly usage caps can stop you mid-flow.

## Slide 6 — Head-to-head
**Price:** Copilot ($10) < Cursor ($20) = Claude ($20)
**Agentic power:** Claude Code > Cursor > Copilot
**Editor experience:** Cursor > Copilot > Claude Code
**Learning curve:** Copilot < Cursor < Claude Code

## Slide 7 — The pick
**My default recommendation:**
Start with Cursor.
If $20 stings → Copilot at $10 gets you 80% of the value.
If you live in the terminal → you already know the answer.

💡 Pro move: many devs run Copilot for cheap daily completions + Cursor/Claude Code for heavy agentic work — $30/mo total.
